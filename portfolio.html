RelatioBench

“Did the interaction respect a pause or withdrawal?”

Inspect source-linked findings in explicitly human-annotated logs. Compare matched runs while checking that eligible task completion did not fall.

python -m pip install relatiobench==0.1.0a2
relatiobench quickstart --output boundary-demo

No model key. Synthetic teaching fixtures; human labels required. No automatic intent or real operator-handoff verification.

Python alpha 0.4.0a1 · BUSL-1.1

VetoLatch

“Has the proposed action actually been approved?”

Record pending, approved or rejected state and local audit events before your integration acts.

python -m pip install vetolatch==0.4.0a1
vetolatch doctor

Trusted local process; in-memory state and caller-supplied actor labels. Authentication and external execution belong to the integrator.

PsychRuleKit

“What do the supplied facts support—and what is missing?”

Evaluate versioned research rule packs against structured facts with explicit unknown values and explainable traces.

Research software, not diagnosis. Rule packs require their own rights and review; copyrighted diagnostic criteria are not distributed.
